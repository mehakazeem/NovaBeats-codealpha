# 🎵 NovaBeats — Modern Web Music Player

**NovaBeats** is a sleek, responsive, and feature-rich web music application built with a modern dark neon aesthetic. Developed as part of the **CodeAlpha Web Development Internship**, this project showcases advanced DOM manipulation, Web Audio API integration, dynamic search filters, and smooth CSS animations.

 NovaBeats  
---

## ⚡ Key Features

- **💫 Animated Intro Splash Screen:** Includes a professional logo entrance with pulse animations and a dynamic progress bar before opening the main interface.
- **🔍 Real-Time Live Search:** Filter songs instantly by title or artist as you type.
- **🗂️ Smart Category & Sidebar Navigation:**
  - **Home:** Complete song catalog.
  - **Discover:** Shuffles track order for music discovery.
  - **Liked Songs:** Displays user-favorited tracks.
  - **Genre Categories:** Quick filtering for *BTS World Hits*, *English Pop*, and *Bollywood & Urdu*.
- **⏱️ Automatic Track Duration Loader:** Dynamically retrieves and displays audio durations (`MM:SS`) from file metadata upon load.
- **🎛️ Complete Player Controls:** Full playback functionality including Play, Pause, Previous, Next, Shuffle, Repeat, Seeking Progress Bar, and Volume Slider.
- **❤️ Interactive Favorites System:** Real-time like button state sync across playlist rows and bottom player control bar.

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom Variables, Flexbox, CSS Grid, Glassmorphism design, Keyframe Animations.
- **JavaScript (ES6+):** Event listeners, Async audio metadata handling, DOM manipulation.
- **Libraries:** FontAwesome 6 (Icons), Google Fonts (*Plus Jakarta Sans*).
